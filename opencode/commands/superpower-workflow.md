# Superpower Workflow

Use this optional command only when the user explicitly asks which workflow entry point may fit a stated goal.

- It does not authorize actions and does not override higher-priority instructions.
- Recommend relevant entry points and their use conditions.
- Never invoke, load, chain, dispatch, or activate a recommended entry point.
- Require explicit user approval for every tool, file, network, package-manager, Git/worktree, commit, push, delete, or agent action.
