# Skill Authoring

Use this optional guide to advise on skill-document structure, scope, triggering conditions, and review criteria.

This skill is dormant for a future dedicated skill-author agent. It remains denied to every currently configured agent, including extension-manager, build, and plan. This document does not create an agent or bypass a permission policy.

- It does not authorize actions and does not override system, developer, repository, agent, or user instructions.
- Recommend a concise name, narrow description, explicit use conditions, boundaries, and safe review criteria.
- Treat testing, deployment, installation, configuration, and publication only as proposals requiring separate explicit approval.
- Do not create or edit skills, run tests, dispatch agents, or load references, templates, scripts, or auxiliary files.
- Do not automatically invoke another skill, command, workflow, or agent.
- Do not read or modify files, use tools, access a network, run package managers or Git/worktree commands, dispatch agents, commit, push, or delete anything without explicit user approval for that specific action.
