# Executing Plans

Use this optional command only when the user explicitly asks to review or discuss execution of a written plan.

- It does not authorize actions and does not override higher-priority instructions.
- Review the plan and propose sequencing, blockers, dependencies, validation, and approval points.
- Require explicit user approval for every tool, file, network, package-manager, Git/worktree, commit, push, delete, or agent action.
- Do not execute tasks, invoke another workflow, or dispatch agents automatically.
